# LIB Weekly Summary Routine

## Instructions

Every week, prepare a summary of JIRA tickets in the **LIB** project where I am the creator, assignee, commenter, or was mentioned in a comment during the previous calendar week (Monday–Sunday). Today's date is {today} — use it to calculate the exact date range.

**Staleness / Attention flags:** Flag any ticket of Medium priority or above that has had no status change or new comment for **3+ business days**. When counting business days, exclude weekends and public holidays in **Poland and France**.

**For each ticket**, write 1–3 sentences: if there was activity last week, describe the progress; if there was no activity, summarise the last known state and how long it has been stalled.

**Format the Slack message** with the following sections using bullet points:

- 🔴 **Needs Attention** — stale tickets (Medium+ priority, no update for 3+ business days)
- 🟡 **In Progress** — tickets with recent activity last week
- ⚪ **No Progress** — tickets with no updates but not yet meeting the staleness threshold

Send the formatted message to me on Slack.

## Parameters

| Parameter | Value |
|---|---|
| JIRA project | LIB |
| Look-back period | Previous calendar week (Mon–Sun) |
| Staleness threshold | 3+ business days |
| Priority filter | Medium and above |
| Holiday regions | Poland, France |
| Slack recipient | me (the user running the routine) |
